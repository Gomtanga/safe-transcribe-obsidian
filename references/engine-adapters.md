# 전사 엔진 어댑터

## 선택 순서

1. 사용자가 특정 엔진이나 모델을 지정했는지 확인한다.
2. 녹음의 민감도와 외부 전송 허용 여부를 확인한다.
3. 현재 환경의 운영체제, CPU/GPU, 여유 저장공간, Python/Node/컨테이너, `ffmpeg`와 `ffprobe` 존재 여부를 조사한다.
4. 실행 가능한 로컬 엔진을 우선한다. 로컬 엔진이 없거나 품질과 시간 요구를 만족하지 못할 때만 외부 API 대안을 제시한다.
5. 작은 대표 구간으로 언어, 속도, 무음 환각, 숫자와 고유명사 품질을 시험한 뒤 전체 작업을 시작한다.

모델 이름만으로 품질을 단정하지 않는다. 같은 모델도 런타임, 양자화, 디코딩 설정, VAD, 이전 텍스트 조건화에 따라 결과가 달라진다.

## 어댑터 계약

어떤 엔진을 사용하더라도 다음 산출물을 만든다.

- 엔진 원시 출력: 재현과 재정규화를 위해 수정 없이 보존한다.
- 실행 기록: 엔진, 모델, 버전, 언어, 디코딩/VAD 설정, 명령 또는 API 유형, 실행 시각을 기록한다.
- 청크 기록: 소스 ID, 청크 ID, 원본 기준 시작과 끝의 오프셋, 성공 여부, 결과 경로, 오류를 기록한다.
- 정규화 입력: 최소한 전체 텍스트 또는 세그먼트 텍스트를 제공한다. 가능한 경우 세그먼트와 단어의 시간, 신뢰도 계열 메트릭, 화자 라벨을 함께 제공한다.

어댑터가 공통 JSON으로 변환할 때 지켜야 할 규칙:

- 없는 시간을 추정해 채우지 않는다.
- 밀리초를 초로 바꾸면 변환 사실을 기록한다.
- 청크 상대 시간을 원본 절대 시간으로 바꿀 때 청크 오프셋을 정확히 한 번만 더한다.
- 겹친 청크의 중복 제거는 텍스트 유사도만으로 확정하지 않는다. 시간 겹침과 오디오 경계를 함께 확인한다.
- 공급자의 confidence, probability, log probability를 하나의 값인 것처럼 섞지 않는다. 원래 이름을 `metrics`에 보존한다.
- 엔진이 제공한 화자 라벨과 후처리 diarization 결과를 구분한다.
- API 키, Authorization 헤더, 서명, 원본 요청 전체는 실행 기록이나 JSON에 저장하지 않는다.

## 대표 엔진 유형

### MLX Whisper

Apple Silicon 로컬 환경에서 유용하다. 설치된 패키지와 모델 캐시를 먼저 확인한다. Hugging Face 다운로드 문제가 있을 때 환경 변수 우회가 필요할 수 있으나, 영구 셸 설정을 바꾸지 말고 해당 실행 범위에만 적용한다. 긴 녹음은 독립 청크와 고유 stem을 사용하고, 모든 청크에 같은 모델과 옵션을 쓴다.

### faster-whisper 또는 Whisper Python

CPU/CUDA 환경에서 사용할 수 있다. 실제 장치와 compute type을 실행 기록에 남긴다. VAD와 `condition_on_previous_text` 변경은 환각과 문맥 연결에 영향을 주므로 시험 구간 결과와 함께 고정한다.

### whisper.cpp

의존성이 제한된 환경에 적합하다. 바이너리 버전, 모델 파일 해시 또는 정확한 모델 식별자, 출력 JSON 옵션을 기록한다. 텍스트 전용 출력만 가능하면 세그먼트 시간과 confidence 검증이 제한됨을 알린다.

### 외부 또는 OpenAI 호환 API

음성 업로드 전에 명시적 허가를 받는다. 공급자, 리전 또는 엔드포인트, 보존 정책을 확인할 수 있는 범위에서 설명한다. 비밀정보는 환경의 비밀 저장소나 일회성 입력으로 전달하고 명령 로그, 노트, 상태 파일에 넣지 않는다. 가능한 경우 verbose JSON 또는 동등한 타임스탬프 출력을 요청한다.

## 청크와 재개

- 엔진 한도가 최우선이다. 한도를 모르면 로컬 장시간 파일의 시작값으로 30분 청크를 사용한다.
- 파일별 고유 ID와 원본 기준 오프셋을 이름에 포함한다. 예: `day06-033__000000-001800`.
- 부분 파일에 최종 파일명을 먼저 쓰지 않는다. 임시 파일을 완성하고 검증한 뒤 원자적으로 이름을 바꾼다.
- 청크별 성공 결과가 있으면 재실행 시 건너뛰고, 엔진, 모델 또는 설정이 바뀌면 기존 결과와 섞지 않는다.
- 원본 시간축으로 합친 뒤 세그먼트가 소스 길이를 넘지 않는지 확인한다.

## 새 형식 연결

`transcript_ops.py normalize`가 인식하지 못하는 구조라면 원시 JSON의 최소 샘플을 조사하고 다음 키만 공통 형식으로 옮기는 얇은 변환기를 만든다.

- 전체 텍스트
- 세그먼트 ID, 시작, 끝, 텍스트
- 단어 시작, 끝, 텍스트, 확률(있는 경우)
- confidence 계열 원래 필드
- 화자 라벨과 출처

원시 파일을 수정하거나 공급자 특유의 수치를 임의의 confidence로 재해석하지 않는다.
