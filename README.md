# Safe Transcribe to Obsidian

<strong>한국어</strong> | [English](README.en.md)

녹음 원본을 보존하면서 전사, 검토, 무타임라인 합본, Obsidian 정리까지 수행하기 위한 에이전트 스킬입니다. 특정 운영체제, ASR 엔진, 모델 또는 공급자에 종속되지 않도록 설계했습니다.

> [!IMPORTANT]
> 이 저장소에는 Whisper나 다른 ASR 엔진이 포함되어 있지 않으며, 스킬을 불러오는 것만으로 전사 환경을 자동 설치하지 않습니다. 현재 환경에서 사용할 수 있는 로컬 엔진을 우선 확인하고, 외부 API에 음성을 업로드해야 할 때는 사용자의 명시적 허가를 먼저 받습니다.

## 주요 기능

- 원본 파일을 읽기 전용으로 취급하고 크기, 형식, 길이, SHA-256을 기록합니다.
- 엔진 원시 출력과 공통 JSON, 검토본, 합본, Obsidian 노트를 분리해 보존합니다.
- 타임스탬프, 반복 문구, 무음 환각 후보 등을 감사하되 의심 구간을 자동으로 삭제하지 않습니다.
- 구간 제외에는 직접 청취 근거를, 문구 교체와 화자 지정에는 직접 청취 또는 권위 있는 자료의 근거를 요구합니다.
- 사용자가 지정한 순서대로 전사를 합치며, 읽기용 TXT에는 타임라인 표식을 추가하지 않습니다.
- 대분류를 먼저 만든 뒤 기존 Obsidian 노트의 frontmatter, 위키링크, 임베드, callout, 수기 메모를 보존하며 정리합니다.
- 구조 검증과 실제 오디오 내용 검수를 구분해 최종 상태를 보고합니다.

## 빠른 시작

저장소를 복제한 뒤 사용하는 에이전트가 인식하는 스킬 디렉터리에 배치합니다.

```bash
git clone https://github.com/Gomtanga/safe-transcribe-obsidian.git
```

에이전트에 다음과 같이 요청할 수 있습니다.

```text
$safe-transcribe-obsidian을 사용해 선택한 녹음의 원본을 보존하면서 전사하고,
타임라인 없는 합본과 대분류 기반의 Obsidian 노트를 만들어 주세요.
```

## 요구사항

- 녹음을 실제로 전사할 별도의 ASR 엔진 또는 사용이 승인된 전사 API
- 보조 도구 사용 시 Python 3.9 이상
- 미디어 길이와 스트림 정보를 확인하려면 `ffprobe` 사용 권장

ASR 엔진이 설치되어 있지 않더라도 스킬은 이를 자동으로 설치하지 않습니다. 사용할 엔진, 모델 다운로드와 저장 공간에 미치는 영향, 외부 전송 허용 여부를 확인한 뒤 작업을 진행해야 합니다.

## 작업 흐름

```text
원본 조사 → ASR 원시 출력 보존 → 공통 JSON 변환 → 기계 감사
→ 오디오 근거 검토 → 무타임라인 합본 → Obsidian 정리 → 납품 검증
```

자세한 규칙과 명령은 [SKILL.md](SKILL.md)를 확인하세요.

## 안전 주의사항

- 원본과 출력 경로를 분리하고, 작업 결과는 별도의 작업 디렉터리에 저장하세요.
- 기계 감사 통과를 전체 오디오 검수 완료로 해석하지 마세요.
- 전사 결과에 비밀번호, 토큰, 개인 식별자가 포함됐는지 공개 또는 공유 전에 확인하세요.
- 실제로 듣지 않은 구간을 확정적으로 삭제하거나 교정하지 마세요.
